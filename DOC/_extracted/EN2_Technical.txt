5. Frontend Architecture
Single-page application (SPA) with React 18 and TypeScript
Three portals: Customer, Loan Officer, Super Admin
Lazy-loaded route components for performance
Design tokens in CSS custom properties (dark/light mode)
Vercel proxies /api/* to the Render backend
6. Backend Architecture
Express.js REST API with TypeScript
JWT authentication middleware with role checks
Rate limiting on auth endpoints
Cron job for daily payment reminders (9 AM Cambodia time)
Telegram bot starts automatically with the server

9. Local Development
git clone https://github.com/ndxdigitalsupport/nexusfinance.git
cd nexusfinance
npm install
cp .env.example .env  # fill in your values
npm run dev
Frontend runs on http://localhost:5173, backend on http://localhost:3001.
