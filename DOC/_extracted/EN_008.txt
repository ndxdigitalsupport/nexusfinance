1. API Overview
Base URL: https://nexusfinance-lof3.onrender.com/api
All endpoints return JSON. Protected endpoints require a Bearer token in the Authorization header.
Status Code
Meaning
200
Success
400
Bad request (missing/invalid fields)
401
Unauthorized (invalid or missing token)
403
Forbidden (insufficient role)
404
Resource not found
429
Rate limited
500
Internal server error

3. Loan Endpoints
GET /api/loans
List all loans. Customers see only their own; admins see all.
Response: 200 [ { id, user_id, name, email, amount, type, status, ... } ]
POST /api/loans
Create a new loan application. Requires authentication.

PATCH /api/loans/:id
Update a loan status. Requires loan-officer or super-admin role.

Type
Required

string

Dedicated actions: PATCH /api/loans/:id/approve, /api/loans/:id/reject, /api/loans/:id/hold — all restricted to loan-officer and super-admin.
4. Transaction Endpoints
GET /api/transactions
List transactions. Customers see their own; admins see all.
POST /api/transactions
Record a new transaction.
POST /api/simulate-payment
Simulate a payment callback (for testing). Triggers Telegram notification.

Endpoint
Method
Description

ABA webhook (HMAC-signed) with approval/decline updates
