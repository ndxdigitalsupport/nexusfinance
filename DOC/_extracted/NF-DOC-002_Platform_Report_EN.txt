1. Project Overview
NexusFinance is a comprehensive fintech lending platform designed for microfinance institutions in Cambodia. The platform serves three user roles — Customers, Loan Officers, and Super Administrators — each with a dedicated portal tailored to their workflow.
2. Portal Features
2.1 Customer Portal
Loan application with step-by-step form (personal info, financial details, loan terms)
Outstanding balance tracking and wallet management
KHQR payment integration (Bakong-compatible)
Transaction history and repayment scheduling
Profile management (name, email, phone, password)
2.2 Loan Officer Portal
Application review dashboard with priority filtering
Credit score analysis and DTI ratio calculation
Direct loan approval/rejection/hold workflow
KYC task management
2.3 Super Admin Portal
Platform-wide analytics and volume tracking
Interest rate and auto-underwrite configuration
User management (roles, password resets)
Full audit log with timestamped entries
System configuration

4. Payment Integration
4.1 KHQR (Bakong)
KHQR is Cambodia's national QR payment standard based on EMVCo. NexusFinance generates KHQR codes for loan repayments and can verify payments via the Bakong API.
Static and dynamic QR generation
Payment verification via MD5 hash
Deeplink generation for mobile banking apps
4.2 ABA PayWay
ABA Bank's PayWay API enables webhook-based payment confirmation.
Sandbox mode currently active
Webhook callback on payment completion
Transaction status tracking
Approved payments are persisted to the ledger (nexus_transactions) and trigger Telegram confirmation

6. Mobile Application
The Android app is an Expo WebView shell that loads the live web application. This allows the platform to be distributed as an installable APK while keeping all logic on the web server.
Expo SDK 57 with React Native WebView
Full-screen immersive design matching the web app
Offline retry screen with brand styling
Custom app icon and splash screen
