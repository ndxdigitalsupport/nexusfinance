៣. Endpoint កម្ចី
GET /api/loans
មើលកម្ចីទាំងអស់។ អតិថិជនមើលតែរបស់ខ្លួន។
POST /api/loans
បង្កើតសំណុំបែបទកម្ចីថ្មី។
PATCH /api/loans/:id
អាប់ដេតស្ថានភាពកម្ចី។ តម្រូវតួនាទី loan-officer ឬ super-admin។
សកម្មភាពផ្តាច់មុខ: PATCH /api/loans/:id/approve, /reject, /hold — កំណត់ត្រឹម loan-officer និង super-admin។

៧. Endpoint PayWay
Endpoint
Method
ការពិពណ៌នា
/api/payway/generate-qr
POST
បង្កើតការទូទាត់ PayWay និងរក្សាទុកកំណត់ត្រា PENDING
/api/payway/verify-payment
POST
ពិនិត្យស្ថានភាពប្រតិបត្តិការ; សម្គាល់ APPROVED + សរសេរក្នុង ledger
/api/payway/callback
POST
ABA webhook (HMAC-signed) ជាមួយការធ្វើបច្ចុប្បន្នភាព approval/decline
/api/payway/simulate-payment
POST
ជំនួយ sandbox ដើម្បីអនុម័តការទូទាត់សម្រាប់តេស្ត
/api/payway/transactions
GET
បញ្ជីប្រតិបត្តិការ PayWay ពីមូលដ្ឋានទិន្នន័យ
ការទូទាត់ PayWay ដែលត្រូវបានអនុម័តត្រូវបានសរសេរទៅ nexus_payway_transactions បង្កើតធាតុ Repayment ក្នុង nexus_transactions ព្រមទាំងការជូនដំណឹងក្នុងកម្មវិធី និង Telegram។
